# Network Fundamentals

이 폴더는 네트워크 기초 개념을 정리하는 공간입니다.  
OSI 7계층, TCP/IP, IP 주소, Subnet, Gateway, DNS, DHCP, ARP, ICMP 등을 다룹니다.

## 정리 목록

| 상태 | 문서 | 내용 |
|---|---|---|
| 진행 중 | [OSI 7계층](./OSI_7_Layers.md) | 네트워크 통신 과정을 계층별로 나누어 이해하고, 장애 원인을 계층별로 분리하는 기준 정리 |
| 예정 | TCP/IP 모델 | OSI 모델과 TCP/IP 모델의 차이 정리 |
| 예정 | Encapsulation / Decapsulation | 데이터가 계층을 거치며 Header와 Trailer가 붙고 제거되는 과정 정리 |
| 예정 | IP Addressing | IPv4 주소 구조와 네트워크/호스트 구분 정리 |
| 예정 | Subnet | 서브넷 마스크와 네트워크 분할 개념 정리 |
| 예정 | Gateway | 서로 다른 네트워크로 나가기 위한 기본 게이트웨이 개념 정리 |
| 예정 | DNS | 도메인 이름을 IP 주소로 변환하는 과정 정리 |
| 예정 | DHCP | IP 주소 자동 할당 과정 정리 |
| 예정 | ARP | IP 주소를 MAC 주소로 변환하는 과정 정리 |
| 예정 | ICMP / Ping | 네트워크 연결 상태 확인 방식 정리 |
