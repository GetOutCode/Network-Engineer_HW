# Network Theory

이 폴더는 네트워크 이론을 계층별, 기능별로 정리하는 공간입니다.  
단순 개념 정리가 아니라, 이후 PNETLab 실습과 Wireshark 패킷 분석으로 연결하는 것을 목표로 합니다.

## 구성

| 구분 | 내용 |
|---|---|
| [01_Network_Fundamentals](./01_Network_Fundamentals/README.md) | OSI 7계층, TCP/IP, IP Addressing, Subnet, Gateway, DNS, DHCP, ARP, ICMP |
| 02_Packet_Analysis | Ethernet Frame, Header, Payload, Trailer, IP/TCP/UDP Header, Wireshark 분석 |
| 03_Switching | MAC Address, VLAN, Access Port, Trunk, 802.1Q, Native VLAN, STP |
| 04_Routing | Routing 개념, Routing Table, Static Routing, Default Route, RIP, OSPF, EIGRP, BGP |
| 05_Network_Security | ACL, NAT, Firewall, VPN, IDS/IPS 기본 개념 |

## 학습 흐름

1. Network Fundamentals
2. Packet Analysis
3. Switching
4. Routing
5. Network Security
6. PNETLab 실습 연계
