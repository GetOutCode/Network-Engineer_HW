# Network Engineer 

네트워크 숙달을 목표로 네트워크 이론, PNETLab 실습, 서버 기초, 과거 보안 솔루션 경험을 정리하는 포트폴리오입니다.

## 목표

- 네트워크 계층별 개념 정리 - 진행중
- VLAN, Trunk, STP, Routing, ACL, NAT 실습
- PNETLab 기반 실무형 네트워크 구성
- Linux 서버 설치 및 기본 운영 정리
- Nexpose, AppScan 등 보안 솔루션 경험 정리
- 기술지원 및 장애 대응 관점의 문서화

## 구성

## 진행 계획

1. OSI 7계층 및 TCP/IP 기본 개념 정리
2. VLAN, Trunk, 802.1Q 이론 정리
3. PNETLab에서 VLAN/Trunk 실습 구현
4. SVI 기반 Inter-VLAN Routing 실습
5. Linux 서버 설치 및 SSH 기본 설정
6. 네트워크와 서버를 연동한 통합 실습 구성
