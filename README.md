# Network Engineer Portfolio

네트워크 엔지니어 취업을 목표로 네트워크 이론, PNETLab 실습, 서버 기초, 현업 기술지원 경험을 정리하는 포트폴리오입니다.

## 목표

- 네트워크 계층별 개념 정리
- Switching, Routing, Network Security 학습
- PNETLab 기반 네트워크 실습 구성
- Linux 서버 설치 및 기본 운영 정리
- 네트워크와 서버를 연동한 통합 실습 구성
- 기술지원 및 장애 대응 관점의 문서화
